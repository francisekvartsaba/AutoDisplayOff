# AutoDisplayOff

[English](README.md) · [Русский](README.ru.md)

Небольшое menu-bar приложение для macOS, которое позволяет **выбрать, какой
экран включён**, когда к MacBook подключён внешний монитор: только экран
ноутбука, только внешний монитор или оба. «Выключен» значит именно выключен
(дисплей отключается на уровне системы, а не просто гасится или закрашивается
чёрным) — как clamshell-режим, но с открытой крышкой, работающей клавиатурой и
трекпадом.

Кликните по иконке в строке меню — откроется небольшое окошко:

- переключатель **Ноутбук / Монитор / Оба**;
- выключатель автоматического режима: при подключении монитора приложение само
  переключается на него (и выключает экран ноутбука);
- текущий статус (включён ли экран ноутбука, сколько мониторов подключено).

Всё приложение — один Swift-файл (`Sources/AutoDisplayOff/main.swift`),
собирается обычным `swift build` и **не требует специальных разрешений**
(ни «Универсального доступа», ни записи экрана, ни прав администратора для
работы).

> [!WARNING]
> **Эта программа выключает экраны и может оставить вас с чёрным экраном.**
> Выбор экрана — новая функция, она проверялась ограниченно (только Apple
> Silicon). В приложении есть несколько подстраховок (см.
> [Меры безопасности](#меры-безопасности)), но если все экраны всё же остались
> выключенными, запустите приложение ещё раз (при старте оно возвращает экраны)
> или перезагрузите Mac. Используйте на свой риск.

## ⚠️ Сначала прочитайте: риски

- **Используется приватный, недокументированный API macOS**
  (`SLSConfigureDisplayEnabled` из `SkyLight.framework`, с запасным вариантом
  `CGSConfigureDisplayEnabled`). Apple может изменить или убрать его в любом
  обновлении без предупреждения. Если после обновления системы перестанет
  работать — это ожидаемо.
- Из-за этого приложение **нельзя распространять через Mac App Store**.
- **Ошибка может оставить экраны чёрными.** Программа поставляется «как есть»,
  без гарантий — см. [LICENSE](LICENSE). Заранее знайте, как вернуть экраны (см.
  [«Как вернуть экран»](#как-вернуть-экран)).
- Автор проверял только на Apple Silicon. Другие конфигурации (Intel, несколько
  внешних мониторов, док-станции с DisplayLink) не проверялись.

## Требования

- macOS 13 (Ventura) или новее.
- Command Line Tools для Xcode (полный Xcode.app **не нужен**):

  ```bash
  xcode-select --install
  ```

  Если сборка падает с сообщением о лицензии Xcode, один раз примите её:

  ```bash
  sudo xcodebuild -license
  ```

## Сборка и запуск

```bash
git clone https://github.com/francisekvartsaba/AutoDisplayOff.git
cd AutoDisplayOff
./build.sh
.build/release/AutoDisplayOff
```

В строке меню (сверху экрана, **не** в Dock — во время работы у приложения нет
иконки в Dock) появится значок монитора. Он краснеет, когда включён только
внешний монитор, и становится оранжевым, когда включён только экран ноутбука.

## Приложение для запуска двойным кликом

```bash
./package_app.sh
```

Рядом со скриптами появится `AutoDisplayOff.app`. Перетащите его в
`/Applications` (и при желании в Dock), чтобы запускать одним кликом.

Приложение не подписано сертификатом разработчика, поэтому при первом запуске
macOS может отказаться его открыть. Нажмите на приложение правой кнопкой (или
Control + клик) → **Открыть** → **Открыть**. Это нужно сделать один раз.

## Автозапуск при входе (по желанию)

```bash
./install_autostart.sh      # включить
./uninstall_autostart.sh    # отключить и остановить
```

## Как пользоваться

| Режим | Экран ноутбука | Внешний монитор(ы) |
| --- | --- | --- |
| **Ноутбук** | включён | выключен |
| **Монитор** | выключен | включён |
| **Оба** | включён | включён |

Переключатель доступен, пока подключён хотя бы один внешний монитор. При
включённом автоматическом режиме подключение монитора выбирает **Монитор**; при
выключенном новый монитор просто добавляется (**Оба**). Отключите последний
монитор — всё включится обратно.

## Как это работает

В macOS нет публичного API «выключить один конкретный экран». AutoDisplayOff
подписывается на уведомления об изменении конфигурации дисплеев
(`CGDisplayRegisterReconfigurationCallback`) и через ~1,5 с после последнего
изменения (чтобы macOS «устаканилась») приводит экраны в соответствие с выбранным
режимом через приватную функцию SkyLight внутри обычной транзакции
`CGBeginDisplayConfiguration` / `CGCompleteDisplayConfiguration`, действующей
только в текущей сессии (перезагрузка всегда сбрасывает изменения).

## Меры безопасности

- Каждое переключение сначала **включает** нужные экраны и только потом
  **выключает** остальные; последний работающий экран никогда не выключается.
- Если экран ноутбука выключен, а внешнего монитора не осталось (его отключили),
  всё автоматически включается обратно.
- При выходе — кнопка **«Выйти»**, `pkill`, завершение сеанса — все экраны
  включаются обратно.
- Список экранов, которые выключило приложение, сохраняется в
  `~/Library/Application Support/AutoDisplayOff/state.json`. Если приложение
  убили или оно упало, пока экран был выключен, **просто запустите его снова**:
  при старте оно вернёт эти экраны.
- Фоновая проверка каждые 15 секунд заново оценивает ситуацию.

## Как вернуть экран

Если какой-то экран остался чёрным:

1. Запустите AutoDisplayOff снова (или откройте его окно и выберите **Оба**) —
   оно возвращает экраны, которые выключило; либо
2. Отключите и снова подключите внешний монитор; либо
3. Перезагрузите Mac (это всегда сбрасывает состояние дисплеев).

## Известные ограничения

- Если приложение убито через `kill -9` / «Завершить принудительно», пока экран
  выключен, он останется выключенным, пока вы не запустите приложение снова (оно
  восстановит экраны при старте) или не перезагрузите Mac.
- Если отключить монитор, пока приложение держит его выключенным (режим
  **Ноутбук**), а потом подключить тот же монитор снова, приложение может снова
  его выключить. Выберите **Оба** или **Монитор**, чтобы вернуть его.
- Зеркалирование дисплеев и циклы сна/пробуждения обрабатываются только
  базово.
- При нескольких внешних мониторах **Ноутбук** выключает их все, а **Монитор**
  оставляет включёнными все; выбора отдельного монитора пока нет.

Pull request'ы, улучшающие это, приветствуются.

## Удаление

```bash
./uninstall_autostart.sh   # только если включали автозапуск
rm -rf AutoDisplayOff      # исходники и результаты сборки
rm -rf /Applications/AutoDisplayOff.app   # если копировали приложение туда
rm -rf ~/Library/"Application Support"/AutoDisplayOff   # сохранённое состояние
```

Приложение не меняет системные файлы; единственное, что оно создаёт, — свой
файл состояния (см. выше), один ключ настроек (`AutoModeEnabled`) для выключателя
и — если включали автозапуск — LaunchAgent в `~/Library/LaunchAgents/`.
