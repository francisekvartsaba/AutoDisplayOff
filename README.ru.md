# AutoDisplayOff

[English](README.md) · [Русский](README.ru.md)

Небольшое menu-bar приложение для macOS, которое **по-настоящему выключает
встроенный экран MacBook** (а не просто гасит подсветку или закрашивает чёрным),
когда подключён внешний монитор, и включает его обратно, когда монитор
отключается. Крышка остаётся открытой, клавиатура и трекпад работают — как
clamshell-режим, но без закрытия крышки.

Кликните по иконке в строке меню — откроется окошко со статусом,
переключателем автоматического режима и кнопкой «Выключить / Включить сейчас».

Всё приложение — один Swift-файл (`Sources/AutoDisplayOff/main.swift`),
собирается обычным `swift build` и **не требует специальных разрешений**
(ни «Универсального доступа», ни записи экрана, ни прав администратора для
работы).

> [!WARNING]
> **Известная проблема безопасности.** Если приложение принудительно завершено
> или упало, пока встроенный экран выключен (например, `pkill`, «Завершить
> принудительно» или сбой), экран может остаться чёрным до перезагрузки Mac, а
> простой повторный запуск приложения его **не** вернёт. Всегда выходите кнопкой
> **«Выйти»** в окне приложения. Используйте на свой риск. Подробнее:
> [Известные ограничения](#известные-ограничения).

## ⚠️ Сначала прочитайте: риски

- **Используется приватный, недокументированный API macOS**
  (`SLSConfigureDisplayEnabled` из `SkyLight.framework`, с запасным вариантом
  `CGSConfigureDisplayEnabled`). Apple может изменить или убрать его в любом
  обновлении без предупреждения. Если после обновления системы перестанет
  работать — это ожидаемо.
- Из-за этого приложение **нельзя распространять через Mac App Store**.
- **Ошибка может оставить экран ноутбука чёрным.** В приложении есть несколько
  подстраховок (см. ниже), но оно поставляется «как есть», без гарантий —
  см. [LICENSE](LICENSE). Используйте на свой риск и заранее знайте, как вернуть
  экран (см. [«Как вернуть экран»](#как-вернуть-экран)).
- Автор проверял только на Apple Silicon с macOS 13+. Другие конфигурации
  (Intel, несколько внешних мониторов, док-станции с DisplayLink) не проверялись.

## Требования

- macOS 13 (Ventura) или новее.
- Command Line Tools для Xcode (полный Xcode.app **не нужен**):

  ```bash
  xcode-select --install
  ```

  Если сборка падает с сообщением о лицензии Xcode, один раз примите её:

  ```bash
  sudo xcodebuild -license
  ```

## Сборка и запуск

```bash
git clone https://github.com/francisekvartsaba/AutoDisplayOff.git
cd AutoDisplayOff
./build.sh
.build/release/AutoDisplayOff
```

В строке меню (сверху экрана, **не** в Dock — во время работы у приложения нет
иконки в Dock) появится значок монитора. Подключите внешний монитор — примерно
через 1,5 секунды встроенный экран выключится. Отключите монитор — включится
обратно.

## Приложение для запуска двойным кликом

```bash
./package_app.sh
```

Рядом со скриптами появится `AutoDisplayOff.app`. Перетащите его в
`/Applications` (и при желании в Dock), чтобы запускать одним кликом.

Приложение не подписано сертификатом разработчика, поэтому при первом запуске
macOS может отказаться его открыть. Нажмите на приложение правой кнопкой (или
Control + клик) → **Открыть** → **Открыть**. Это нужно сделать один раз.

## Автозапуск при входе (по желанию)

```bash
./install_autostart.sh      # включить
./uninstall_autostart.sh    # отключить и остановить
```

## Как это работает

В macOS нет публичного API «выключить один конкретный экран при открытой
крышке». AutoDisplayOff подписывается на уведомления об изменении конфигурации
дисплеев (`CGDisplayRegisterReconfigurationCallback`); когда появляется внешний
монитор, ждёт ~1,5 с, пока macOS его «устаканит», и выключает встроенный экран
через приватную функцию SkyLight внутри обычной транзакции
`CGBeginDisplayConfiguration` / `CGCompleteDisplayConfiguration`, действующей
только в текущей сессии (перезагрузка всегда сбрасывает изменения).

## Меры безопасности

Встроенный экран автоматически включается обратно, когда:

1. отключается последний внешний монитор;
2. вы выходите из приложения кнопкой **«Выйти»** в его окне (или ⌘Q);
3. вы выключаете автоматический режим переключателем в окне;
4. фоновая проверка (каждые 15 секунд) видит, что экран выключен, а внешнего
   монитора нет.

Кнопка ручного выключения не работает, если внешний монитор не подключён.

## Как вернуть экран

Если встроенный экран остался чёрным:

1. Отключите и снова подключите внешний монитор, либо
2. Перезагрузите Mac (это всегда сбрасывает состояние дисплеев).

## Известные ограничения

- **Если приложение принудительно завершено или упало, пока экран выключен**
  (например, `pkill`, «Завершить принудительно» в Мониторинге системы или сбой),
  подстраховки выше не сработают, и встроенный экран может остаться выключенным
  до перезагрузки Mac. Всегда выходите кнопкой **«Выйти»**.
- После сбоя простой повторный запуск приложения экран **не** вернёт, так как
  приложение ищет встроенный дисплей только среди активных. В этом случае
  перезагрузите Mac.
- Автоматический режим реагирует только на подключение и отключение дисплеев и
  отдельно не обрабатывает сон/пробуждение.

Pull request'ы, улучшающие это, приветствуются.

## Удаление

```bash
./uninstall_autostart.sh   # только если включали автозапуск
rm -rf AutoDisplayOff      # исходники и результаты сборки
rm -rf /Applications/AutoDisplayOff.app   # если копировали приложение туда
```

Приложение не меняет системные файлы; единственное, что оно может создать, —
свой LaunchAgent в `~/Library/LaunchAgents/` (если включали автозапуск) и один
ключ настроек (`AutoModeEnabled`) для состояния переключателя.
